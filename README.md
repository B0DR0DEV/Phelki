# Пчёлок уважаешь?

Мемная мобильная игра про пчёл. При первом запуске дед-пасечник спрашивает: «Ты пчёлок уважаешь?» — и ответ навсегда определяет сторону.

Дизайн-документ: https://claude.ai/artifact/8rBaMacLPdPtaowSfgRYSP

## Что уже есть (часть 1, «Пасека»)

- Вопрос «Ты пчёлок уважаешь?» при первом запуске; передумать можно один раз в первые 10 минут.
- Живое 3D-меню: камера облетает пасеку, вокруг улья кружит рой. Если ответил «Нет» — весь рой зависает перед камерой.
- Вылет на 3 минуты по даче:
  - веди пальцем — пчела летит следом; отпустил — зависает, её сносит ветром;
  - быстрый свайп — рывок; рывком можно протаранить осу;
  - зависни над цветком — собираешь пыльцу; чем больше несёшь, тем пчела толще и медленнее;
  - неси пыльцу в улей — она становится мёдом, за 20+ за раз дед даёт бонус.
- Опасности: стёкла теплицы и стены (удар — пыльца рассыпается облачками, их можно подобрать), простыни на верёвке, деревья, банка варенья (прилипаешь, но +3 пыльцы), соседский вентилятор, порывы ветра, осы-гопники в кепках у мусорки (отжимают пыльцу).
- Бабкина клумба: каждый вылет там распускается один золотой редкий цветок.
- Итоги вылета, рекорд, сохранение мёда на телефоне.
- **Побег за людей** (для ответивших «Нет»), против 12 пчёл-ботов:
  - тот же один палец: ведёшь — дачник бежит следом, свайп — перекат (пока катишься, не жалят);
  - кнопка «Мухобойка» сбивает пчёл перед собой на 3 секунды, «Дымарь» усыпляет всех вокруг (перезарядка 10 с);
  - утащи 3 банки мёда (места каждый раз разные) и стой у машины у ворот, пока она заводится;
  - каждый укус раздувает лицо и руки и замедляет; отёк 100% — «увезли на скорой»;
  - итоги: «Ты сбежал!» с лучшим временем, «Увезли на скорой», «Не успел».
- Фразы деда на все события.

Пока **нет**: друзей, набегов и рейтингов (нужен сервер), живого онлайна (часть 3), звука, настоящих моделей.

## Важно про графику

Сейчас все модели — временные заглушки из простых форм, только чтобы проверить, весело ли играть. Настоящие модели подключаются без программирования, см. «Как заменить заглушки на модели».

## Как открыть проект (один раз)

Нужно: [Unity Hub](https://unity.com/download) и **Unity 6 LTS** с модулем **Android Build Support** (галочки OpenJDK и Android SDK & NDK тоже).

1. Установи [GitHub Desktop](https://desktop.github.com/) и склонируй этот репозиторий, например в `Документы/Phelki`.
2. В Unity Hub создай **новый** проект по шаблону **Universal 3D** с любым именем, например `PhelkiTemp`. Дождись, пока откроется, и закрой Unity.
3. Из папки `PhelkiTemp` скопируй в `Документы/Phelki`:
   - папки `Packages` и `ProjectSettings` целиком;
   - всё содержимое папки `Assets` — в папку `Assets` репозитория (там уже лежит `Phelki`, её не трогай).
4. В Unity Hub: **Add → Add project from disk** → выбери `Документы/Phelki`. Открой.
5. Открой сцену `Assets/Scenes/SampleScene` и нажми **Play**. Игра соберётся сама.
6. В окне Game выбери вертикальное разрешение (например 1080×1920). Мышь работает как палец.
7. В GitHub Desktop сделай коммит — так проект с настройками сохранится в репозитории.

Если в консоли Unity появились красные ошибки — пришли их текст, поправлю.

**Снова увидеть вопрос деда:** меню **Phelki → Сбросить профиль**. Так же можно проверить обе стороны: ответь «Нет», чтобы попасть в побег, или нажми «Я передумал» в первые 10 минут.

## Как собрать на телефон (Android)

1. **File → Build Profiles → Android → Switch Platform.**
2. **Player Settings:** Company Name, Product Name «Пчёлок уважаешь?», Package Name `com.b0dr0dev.phelki`, Default Orientation — Portrait.
3. Включи на телефоне режим разработчика и отладку по USB, подключи кабелем.
4. **Build And Run.**

## Как заменить заглушки на модели

1. Положи модели в проект (купленный пак или от художника). Пчела и оса должны смотреть вперёд по оси Z.
2. **Assets → Create → Phelki → Набор арта.** Назови файл `PhelkiArtSet` и положи в папку `Assets/Phelki/Resources` (создай её).
3. Перетащи модели в поля набора. Пустые поля игра заменит заглушками, логика не меняется.

## Устройство кода

```
Assets/Phelki/Scripts/
  Core/   запуск, ход игры, профиль, ввод, фразы деда, набор арта
  Bee/    пчела игрока, её вид, камера
  World/  дача, цветы, улей, пыльца, осы, варенье, вентилятор, рой, машина
  Human/  побег за людей: дачник, пчёлы-боты, банки мёда, дым, матч
  UI/     экраны и элементы интерфейса
```

Всё собирается кодом при нажатии Play, поэтому сцену руками собирать не нужно. Чтобы отключить автосборку в какой-то сцене, повесь на любой объект компонент `ManualSceneMarker`.
