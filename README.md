# Пчёлок уважаешь?

Мемная мобильная игра про пчёл. При первом запуске дед-пасечник спрашивает: «Ты пчёлок уважаешь?» — и ответ навсегда определяет сторону.

Сделано на [Godot](https://godotengine.org) 4.7 — бесплатно, без регистрации и лицензий.

- **Играть в браузере:** https://b0dr0dev.github.io/phelki/ (после включения GitHub Pages, см. ниже)
- **Скачать APK для Android:** https://github.com/B0DR0DEV/phelki/releases/latest/download/phelki.apk
- **Дизайн-документ:** https://claude.ai/artifact/8rBaMacLPdPtaowSfgRYSP

## Что есть в игре

При первом запуске дед спрашивает «Ты пчёлок уважаешь?». Ответ определяет сторону и набор режимов; передумать можно один раз в первые 10 минут.

**За пчёл:**
- **Вылет** — собирай пыльцу и неси в улей: осы-гопники, варенье, вентилятор, ветер, стёкла, золотой бабкин цветок.
- **Перегонки** — ты и 5 пчёл-ботов, золотые кольца, 2 круга.
- **Охота на дачников** — ты в рою из 15 пчёл ловишь трёх дачников-ботов, пока они не утащили банки и не уехали.
- **Медведь-рейдер** — медведь идёт к улью за мёдом, ты и 8 пчёл-помощниц жалите его; рывок жалит сильнее.
- **Флаппи-пчела** — мини-игра: тапай и пролетай между досками и водосточными трубами.

**За людей («неуважающих»):**
- **Побег** — 3 банки мёда и к машине; мухобойка, дымарь, перекат, отёк от укусов.
- **Побег втроём** — ты и два дачника-бота против 16 пчёл, 5 банок.
- **Выживание** — пчёлы прилетают волнами, держись сколько сможешь.
- **Флаппи-пчела** — даже неуважающим можно.

**Для всех:**
- **Онлайн-охота** — дачники против пчёл по сети, до 4 + 16 игроков, пустые места занимают боты. Свой сервер или комната с телефона в одном Wi-Fi (см. [server/README.md](server/README.md)).
- **3 карты:** Дача, Двор (хрущёвки, гаражи, детская площадка, бабушка с вареньем, вечер), Поле подсолнухов (мельница, стога, пугало с осами, трактор).
- **Вид от первого лица** — кнопка «Вид» в меню и прямо в игре. Палец работает как руль: левее центра — поворот налево.
- **Обучение** — при первом заходе в каждый режим, пошагово. В меню можно включить заново.
- Вибрация на укусах и ударах (отключается в меню), рекорды по всем режимам, мёд как общая валюта.

Пока **нет**: друзей и рейтингов, набегов на ульи, скрещивания пород, звука и настоящих моделей.

## Облачная сборка

Каждый пуш в `main` запускает GitHub Actions (вкладка **Actions → Сборка игры**):

1. **Автотест** — игра сама проходит все режимы без экрана, потом сервер и два клиента играют онлайн-матч. Если что-то сломалось, дальше сборка не пойдёт.
2. **APK** — выкладывается в [Releases](https://github.com/B0DR0DEV/phelki/releases). Ссылка выше всегда ведёт на последнюю версию.
3. **Веб-версия** — публикуется на GitHub Pages.
4. **Сервер онлайн-охоты** — Docker-образ `ghcr.io/b0dr0dev/phelki-server:latest`.

Никаких секретов добавлять не нужно.

### Один раз: включить сайт

Репозиторий → **Settings → Pages → Build and deployment → Source: GitHub Actions**. После этого перезапусти сборку (Actions → Сборка игры → Run workflow), и игра появится по адресу https://b0dr0dev.github.io/phelki/

### Как поставить APK на телефон

Открой на телефоне ссылку «Скачать APK» выше, скачай файл и открой его. Разреши установку из неизвестных источников. Новые версии ставятся поверх старых.

APK подписан **тестовым** ключом из `ci/debug.keystore` — он не секретный и подходит только для проверки. Для Google Play и RuStore понадобится свой ключ, который хранится в секретах репозитория.

## Как открыть проект у себя

1. Скачай [Godot 4.7](https://godotengine.org/download) (Standard, не .NET) — это один файл, установка не нужна.
2. Склонируй репозиторий (например, через [GitHub Desktop](https://desktop.github.com/)).
3. В Godot: **Import** → выбери файл `project.godot` → **Import & Edit**.
4. Нажми **▶** (F5). Мышь работает как палец.

**Снова увидеть вопрос деда:** удали файл профиля — в Godot меню **Project → Open User Data Folder**, файл `profile.json`.

## Как заменить заглушки на модели

Положи модель в папку `art/` с нужным именем (например, `art/bee.glb`) — игра подхватит её сама. Список имён и требования — в [art/README.md](art/README.md).

## Проверка без экрана (для разработки)

```
godot --headless --path . -- --autotest
```

Игра ускоренно проходит обе стороны и печатает `AUTOTEST OK`. С `--shots=/папка` на виртуальном экране сохраняет скриншоты ключевых моментов.

## Устройство кода

```
main.tscn              пустая сцена; всё собирается кодом
scripts/core/          ход игры, профиль, фразы деда, палец, формы-заглушки, автотест
scripts/bee/           пчела игрока, её вид, камера
scripts/world/         дача, цветы, улей, пыльца, осы, варенье, вентилятор, рой, машина
scripts/human/         побег: дачник, пчёлы-боты, банки мёда, дым, матч
scripts/ui/            экраны и элементы интерфейса
fonts/                 шрифт Rubik (свободная лицензия OFL)
art/                   сюда кладутся настоящие модели
ci/                    скрипты облачной сборки
.github/workflows/     облачная сборка
```
