# Модели для игры

**Стиль:** «дачная игрушка» — скруглённые, будто точёные формы, плоские цвета без текстур или с простыми, крупные детали. Контур и мультяшный свет игра добавит сама, если у модели материал без прозрачности. Палитра — в `scripts/core/palette.gd`.

Сейчас всё в игре — временные заглушки из простых форм. Чтобы заменить любую из них настоящей моделью, положи файл сюда с нужным именем. Код менять не нужно: игра сама найдёт модель при запуске.

Формат — **glTF** (`.glb` или `.gltf`), его экспортирует Blender и большинство художников. Можно и готовую сцену Godot (`.tscn`).

| Файл | Что это | Важно |
|---|---|---|
| `bee.glb` | Пчела (игрок, рой, боты) | Смотрит вперёд по оси +Z, длина ~0.8 м. Крылья назови `Крыло_Л` и `Крыло_П` — тогда игра сама будет ими махать |
| `wasp.glb` | Оса-гопник | Как пчела, можно в кепке |
| `human.glb` | Дачник | Рост ~2 м, ноги на нуле, смотрит по +Z |
| `hive.glb` | Улей | Вход смотрит к камере (по −Z) |
| `flower.glb` | Цветок | Высота ~0.75 м |
| `house.glb` | Дом | ~10 × 5 × 8 м |
| `greenhouse.glb` | Теплица | ~6 × 3 × 4 м |
| `tree.glb` | Дерево | Высота ~5 м |
| `table.glb` | Стол | Столешница на высоте 0.85 м |
| `jam_jar.glb` | Банка варенья | |
| `fan.glb` | Вентилятор соседа | Дует по +Z |
| `trash_can.glb` | Мусорка | |
| `car.glb` | Машина дачника | Длина вдоль оси X, ~4 м |
| `honey_jar.glb` | Банка мёда для побега | |

Если у модели нет своих коллизий, игра сама добавит невидимую коробку по её размерам — в неё можно будет врезаться.

### Для новых режимов и карт

| Файл | Что это | Важно |
|---|---|---|
| `bear.glb` | Медведь-рейдер | Длина ~3 м, смотрит по +Z |
| `tractor.glb` | Трактор на карте «Поле» | Как машина: длина вдоль X |

Хрущёвки, гаражи, площадка, мельница, сарай, пугало и стога пока строятся только из заглушек — их можно заменить позже тем же способом.
