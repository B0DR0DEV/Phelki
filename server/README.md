# Сервер онлайн-охоты

Сервер — это та же игра Godot, запущенная без экрана с ключом `--server`. Он сам считает матч: дачники против пчёл, пустые места занимают боты. После каждого матча карта меняется.

## Где его запустить

Нужна машина, которая работает постоянно и доступна из интернета (VPS). Подойдёт самый дешёвый сервер: 1 ядро, 1 ГБ памяти. Сервер держит одну комнату на 20 игроков.

GitHub Actions собирает готовый образ при каждом пуше:

```
docker run -d --restart=always -p 8910:8910 ghcr.io/b0dr0dev/phelki-server:latest
```

Без Docker:

```
godot --headless --path . -- --server --port=8910 --rotate-maps
```

Ключи: `--port=8910`, `--map=dacha|yard|field` (стартовая карта), `--rotate-maps` (менять карту после матча).

## Подключение

- **Телефоны (APK)** подключаются напрямую: в игре «Онлайн-охота» → адрес `IP-сервера` (порт 8910 подставится сам).
- **Браузер (сайт на GitHub Pages)** открывается по https, поэтому браузер разрешит только защищённое подключение `wss://`. Поставь перед сервером Caddy — он сам получит сертификат:

```
# /etc/caddy/Caddyfile
игра.твой-домен.ru {
    reverse_proxy localhost:8910
}
```

Тогда адрес для игры: `wss://игра.твой-домен.ru`. Его можно вписать в `scripts/net/net.gd` (константа `DEFAULT_SERVER`), чтобы он подставлялся сам.

## Без сервера

Друзья в одном Wi-Fi могут играть без всякого сервера: один нажимает «Создать комнату (Wi-Fi)», остальные вводят показанный адрес.
